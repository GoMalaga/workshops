# Talleres de Go

Material del alumnado de los talleres de Go de la comunidad Golang Málaga.
Un proyecto único que crece sesión a sesión: un sistema de reservas de stock
en el que nunca se vende más de lo que hay.

| Taller | Carpeta | Qué se construye                                   |
|--------|---------|----------------------------------------------------|
| Go 1   | `go1/`  | El motor: tipos, errores y tests, sin HTTP todavía |

Cada carpeta es un módulo de Go independiente con su propio README, que es
donde empieza cada taller:

```bash
git clone https://github.com/GoMalaga/workshops.git
cd workshops/go1
```

## Checkpoints

Los puntos de rescate se publican como tags a lo largo de cada sesión, no
antes. Si te quedas descolgado, `git fetch --tags` y salta al que toque; el
README de cada taller dice cuáles hay.
